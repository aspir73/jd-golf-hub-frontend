# JD Golf Hub - Frontend

싱글파일 HTML/CSS/JS (JD Times와 동일한 패턴). 별도 빌드 과정 없이 정적 호스팅(Cloudflare Pages 등)에 `index.html` 하나만 올리면 된다.

## 로컬 확인

`index.html`을 브라우저로 바로 열거나, 아래처럼 로컬 서버로 띄운다.

```bash
npx serve .
```

## 배포 전 설정

`index.html` 상단 `<script>` 안의 `CONFIG.API_BASE` 값을 배포한 백엔드 Worker 주소로 교체한다.

```js
const CONFIG = {
  API_BASE: 'https://jd-golf-hub-backend.<your-subdomain>.workers.dev',
};
```

## 배포

Cloudflare Pages에 이 폴더를 그대로 연결 (JD Times와 동일 방식). 커맨드라인으로는:

```bash
npx wrangler pages deploy . --project-name=jd-golf-hub
```

## 현재 구현 범위

**MVP1**
- **날씨**: 위치 권한 허용 → 오늘 시간대별 예보 + 기온/바람/강수확률 기반 복장 추천
- **스코어**: 수동 입력/수정/삭제 (골프장, 코스, 총타수, FIR/GIR/퍼트, 평점, 출처, 메모)
- **통계**: 최근10 평균, 베스트 스코어, 총 라운드, 평균 FIR/GIR/퍼트, 코스별 평균
- **홈**: 위 통계 요약 + 날씨 요약 대시보드

**MVP2**
- **예약 탭 - 즐겨찾기 골프장**: 카카오맵 키워드 검색으로 주소/연락처/좌표 자동완성 → 코스 목록·카트비·캐디피·예약 링크 등록/수정/삭제
- **예약 탭 - 동반자**: 이름/연락처/카톡 닉네임 등록 및 관리
- **예약 탭 - 정산**: 참가자 선택 → 항목별(그린피/카트비/캐디피/식사 등) 정산 방식(각자결제/전원1N/선택인원1N) + 결제자 입력 → 1인당 정산액과 송금 목록 자동 계산 + 카카오톡 공유문구 복사
- **맛집 탭**: 위치 기반 카카오 로컬 검색, 라운딩 전(해장)/후(한 끼)/카페 타이밍 필터, 카카오맵 길찾기 딥링크, 개인 즐겨찾기 맛집 저장

**MVP3**
- **공용 이미지 인식 컴포넌트**: 사진 업로드 → 브라우저에서 리사이즈/JPEG 압축 → Worker 경유 Claude Vision 호출 → 구조화 데이터로 폼 자동 채움 (스코어/영수증 화면에서 재사용)
- **스코어 다이얼로그**: 스코어카드/보이스캐디/스마트스코어 캡처 사진 인식 → 골프장·코스·날짜·총타수·FIR/GIR/퍼트 자동 입력 + 출처 자동 태깅
- **라운드 종류 구분**: 필드/스크린골프(골프존 등) 태그 → 통계에서 별도 집계
- **중복 등록 확인**: 같은 날짜·골프장 기록이 이미 있으면 저장 전 확인 안내
- **통계 필터**: 출처(직접입력/보이스캐디/스마트스코어)·라운드 종류(필드/스크린)별 필터링
- **정산 다이얼로그**: 영수증 사진 인식 → 항목명·금액을 정산 항목으로 자동 추가

**MVP4**
- **홈 탭 - 설정**: 집 주소 등록(카카오 검색), 선호 라운딩 시간대 설정 — 가중치 점수 계산의 기준값
- **예약 탭 - 골프장 조건검색**: 날짜·시간대·지역·예약유형(본인예약/조인·백업)으로 골팡 실시간 검색 → 지역/시간/골프장/홀수/그린피/캐디유무/모집조건 리스트, 결과 클릭 시 내 라운딩 이력 간단 조회
- **예약 탭 - 동반예약(백업) 비교**: 검색 결과에서 여러 후보를 선택해 비교 그룹 생성 → 거리·내 평가·그린피·시간대 4개 항목을 슬라이더로 실시간 가중치 조정하며 비교 → 최고 점수 골프장 "추천" 배지

**MVP5**
- **예약확정 메시지 붙여넣기**: 골팡/골프장에서 받은 카카오톡·문자 확정 메시지를 그대로 붙여넣으면 AI가 유형·골프장·일시·그린피·동반인원·취소가능성 등을 추출 → 검토/수정 화면을 거쳐 저장
- **가예약↔확정 자동 매칭**: 같은 골프장·날짜의 기존 가예약 기록과 매칭되면 "확정"으로 갱신하고, 같은 동반예약 그룹의 나머지 항목은 자동으로 "취소 검토 대상" 배지 표시
- **예약 기록 관리**: 상태(가예약/확정/취소예정/취소완료) 추적, 취소 가능 마감일 D-day 배지(홈 탭에 D-2~D-1 임박 리마인드), 조인 건의 "취소불가·예약금" 경고 배지
- **예약 현황 리포트 복사**: 현재 예약 현황을 카카오톡 공유용 문구로 정리해 클립보드 복사
